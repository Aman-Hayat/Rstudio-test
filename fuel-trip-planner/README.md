# Trip Fuel Planner

A Shiny app that estimates trip fuel use and cost from the built-in `mtcars` dataset. The live app includes its own beginner instructions.

Run locally after installing `shiny`:

```r
shiny::runApp("fuel-trip-planner")
```

The five-slide RStudio Presenter source is `pitch.Rpres`. Open it in RStudio and preview it to evaluate the embedded R chunk.
